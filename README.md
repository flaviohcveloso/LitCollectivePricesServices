# Lit Collective — Services & Pricing (earlier copy)

An earlier copy of the Lit Collective services and pricing page. The `index.html` here is identical to the one in the main repository, which is the version that is maintained and deployed.

**Main repository:** [flaviohcveloso/LitCollectivePrices](https://github.com/flaviohcveloso/LitCollectivePrices)
**Live:** [lit-collective-prices.vercel.app](https://lit-collective-prices.vercel.app)

![Services and pricing](https://raw.githubusercontent.com/flaviohcveloso/LitCollectivePrices/main/docs/home.jpg)

See the main repository for what's inside, the stack, screenshots and how to run it.

## Run locally

No install needed. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
